# 拼音战机 · Pinyin Defense

一款基于 **HTML5 Canvas + 原生 JavaScript** 的打字射击小游戏。全部代码内联在单个 HTML 文件中，零依赖、无需构建、无需部署，双击即可在浏览器中运行。

## 项目特性

- **单文件交付**：HTML / CSS / JS 全部内联，一个文件即完整游戏
- **三档难度**：初级 / 中级 / 高级，各自独立的词库与难度参数
- **核心玩法**：输入敌机显示的拼音即可锁定目标并发射子弹击落它
- **连击系统**：连续击毁累积倍率，最高 3 倍得分
- **丰富反馈**：爆炸粒子、流动星空、Web Audio 合成音效（无外部音频文件）
- **本局统计**：打字总数、正确率、打字速度、最高分（localStorage 本地保存）
- **便捷操作**：空格暂停 / 继续，Esc 或点击按钮返回主界面

## 运行方式

直接用浏览器打开 `拼音战机.html`（或仓库首页的 `index.html`）即可开始游戏，不需要安装任何依赖，也不联网。

## 操作说明

| 操作 | 说明 |
|---|---|
| 点击难度按钮 | 选择初级 / 中级 / 高级并开局 |
| 输入拼音 | 锁定对应敌机，逐字输入，已输入部分显示为绿色 |
| 输入错误 | 自动重置当前输入，不扣分（但会中断连击） |
| 空格键 | 暂停 / 继续 |
| Esc 键 | 从游戏中或暂停页返回主界面 |
| Enter 键 | 游戏结束后快速重开 |

放跑敌机会扣 1 点生命并中断连击；生命耗尽游戏结束。

## 难度配置

采用「目标在场数」驱动生成机制：屏幕始终维持固定数量的敌机，缺一架补一架，一架接一架进场，击毁后快速补位，不会出现瞬间铺满或长时间空窗。

| 难度 | 目标在场数 | 硬上限（随等级增长封顶） | 补位间隔 | 下落速度 |
|---|---|---|---|---|
| 初级 | 3 | 4 | 700ms | 0.55 → 0.90 |
| 中级 | 4 | 5 | 550ms | 0.80 → 1.30 |
| 高级 | 5 | 6 | 420ms | 1.05 → 1.75 |

等级计算：`level = 1 + floor(score / 400)`，每 400 分升 1 级。以初级为例，各项难度参数在 LV.25（约 9600 分）前陆续封顶，之后难度不再增长，纯为刷分。
