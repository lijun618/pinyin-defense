# 拼音战机 · 开发过程全记录

本文档完整记录《拼音战机》打字小游戏从需求梳理、分阶段开发、多轮调优到 Bug 修复的全过程。

---

## 一、需求梳理 + 方案设计（任务 1）

### 1.1 游戏流程图

```
游戏启动(START)
    ↓ 选择难度
  游戏进行中(PLAYING)
    ↓ 主循环每帧
  ┌─────────────────────────────┐
  │ 生成敌机(按策略补位)        │
  │   ↓                         │
  │ 敌机从顶部向下移动          │
  │   ↓                         │
  │ 监听键盘输入                │
  │   ├─ 首字符匹配 → 锁定敌机  │
  │   ├─ 逐字匹配 ──┐           │
  │   └─ 输错 → 重置输入(不扣分)│
  │                 ↓           │
  │          完整匹配成功       │
  │                 ↓           │
  │       发射子弹 → 命中 → 爆炸│
  │                 ↓           │
  │       加分(×连击倍率) 连击+1│
  └─────────────────────────────┘
    ↓                    ↓
敌机漏过底部→扣血断连   空格→暂停(PAUSED)
    ↓                    ↓
生命≤0 → 游戏结束     空格→继续 / Esc→主界面
    ↓
结束页(OVER)：展示分数/统计 → Enter重开 或 返回主界面
```

### 1.2 功能清单

| 类别 | 功能 |
|---|---|
| 必选 | 三状态页面、Canvas 主循环、三套拼音词库、定时/补位生成敌机、敌机下落与漏过扣血、键盘实时输入、前缀匹配校验、击毁/爆炸/加分、错误重置不扣分、连击倍率（1~3x）、玩家飞船与子弹、分数驱动难度、开局难度选择、爆炸粒子、星空、HUD 美化、空格暂停 |
| 可选（均已实现） | 本局统计（打字数/正确率/速度）、localStorage 最高分、Web Audio 合成音效 |

### 1.3 技术实现方案

纯 HTML5 Canvas + 原生 JS，零依赖。DOM 覆盖层做开始/暂停/结束三页，Canvas 内绘制游戏场景与 HUD；状态机 `START/PLAYING/PAUSED/OVER` 驱动；`requestAnimationFrame` + 时间增量 `dt` 保证帧率无关运动（对 `dt>200ms` 钳制防切标签页跳变）；Web Audio 振荡器合成音效，全程保持单文件。

### 1.4 变量规划

| 变量 | 含义 |
|---|---|
| `hp` / `score` / `combo` / `maxCombo` / `level` / `kills` | 生命、分数、当前连击、最大连击、等级、击毁数 |
| `diffKey` | 难度档位 easy/normal/hard |
| `enemies` / `bullets` / `particles` / `stars` | 实体池 |
| `currentInput` / `target` | 当前输入串 / 锁定敌机 |
| `alive` / `aliveCap` / `gap` | 目标在场数 / 硬上限 / 补位间隔（见任务 6 最终形态） |

## 二、分阶段开发（任务 2 ~ 任务 7）

### 任务 2｜基础框架搭建
创建 `960×640` Canvas；实现开始页 / 游戏中 / 游戏结束页三个状态；预留分数、血量条、难度选择按钮 UI；`requestAnimationFrame` 主循环 `loop()`。

### 任务 3｜词库 + 敌机生成
构建三套词库：`WORDS.easy`（单韵母/基础声母，四级词汇）、`WORDS.normal`（常用双音节，四级词汇）、`WORDS.hard`（复杂组合，六级词汇），每条目含 `{py, zh, en}`；按难度生成绑定拼音的敌机；敌机自动下落，漏过底部扣血。

### 任务 4｜核心打字交互
`handleChar()` 前缀锁定：无目标时按首字母锁定最靠下的敌机，有目标时逐字符校验；完全匹配 → `completeMatch()` 发射子弹，命中后 `destroyEnemy()` 结算爆炸/加分/连击；错误 → `wrongInput()` 重置输入不扣分；倍率 `combo>=6 → ×3`、`combo>=3 → ×2`。

### 任务 5｜玩家飞船 + 子弹
`drawPlayer()` 绘制底部飞船；匹配成功生成追踪子弹向上飞行，碰撞敌机触发击毁判定。

### 任务 6｜难度动态调节
`level = 1 + floor(score/400)`；随等级提升在场数、补位速度、下落速度，各有硬上限；开局手动选择难度。（最终参数见第四节调优记录。）

### 任务 7｜视觉特效与 UI
`createExplosion()` 爆炸粒子、110 颗流动星空、分数/血量/连击倍率 HUD、空格暂停/继续、Esc 返回主界面、Canvas 右上角常驻「主界面」按钮。

## 三、测试与 Bug 修复（任务 8）

采用 Node.js `vm` 模块模拟 DOM / Canvas 环境，对提取出的脚本做语法校验与行为模拟（生成节奏、打字击毁、连击计分、漏过扣血、长时间运行稳定性）。

自测中发现并修复的真实 Bug：

1. **`stars` 数组未初始化**：首帧渲染即报错。修复：声明后立即 `stars = []`。
2. **匹配成功后 `target` 未释放**：子弹飞行期间误触按键会打断连击。修复：`completeMatch()` 中立即清空输入锁 `target=null; currentInput=''`，玩家可马上匹配下一架。
3. **`dying` 敌机停止下降**：更新循环原为 `if(e.dead || e.dying) continue`，导致已匹配敌机悬停，看起来像"输入冻结了敌机"，且占据泳道阻塞生成。修复：改为 `if(e.dead) continue`，所有存活敌机持续下降；已匹配敌机若在子弹命中前漏出，按击毁加分不扣血。

## 四、多轮调优记录（重点）

游戏生成机制经历了多轮基于实际体验的调优，这是本项目最核心的迭代过程。

### 第 1 轮：初级数量爆炸
**问题**：原逻辑生成间隔随等级每次 −70ms（下限 320ms，约 187 架/分），同时单批生成数从 1 涨到 3，两者相乘导致数量成倍暴涨。
**修复**：改为以「每分钟敌机数」为直接控制指标，间隔由 `60000/rate` 反推，取消批量递增（每次固定 1 架），并设硬上限。三档速率：初级 12→15、中级 20→28、高级 32→48 架/分。

### 第 2 轮：等级增长曲线
**问题**：线性步进在 Lv7 就顶到上限，之后完全不增长，玩家感觉"缺增长"。
**修复**：改用平滑渐近曲线 `rate = min + (max-min)×(1-e^(-(L-1)/τ))`，全程缓慢增长、永远逼近但不超上限，再加 `Math.min` 双保险。

### 第 3 轮：生成位置错误（屏幕只有一架）
**问题**：模拟发现新机生成位置 `spawnY = Math.min(-46, top-100)` 会不断往上堆到 y=-146/-246（画面外），开局预置也全在屏幕外，导致屏幕上长期只有一架、击毁后等 1~2 秒才进画面。
**修复**：新机改为从画面顶边（y≈-28）飞入，开局铺开数架在画面内不同高度。

### 第 4 轮：生成机制重构（关键）
**问题**：定时生成 + 开局预置铺满的机制，必然导致"瞬间四五架"和"打完空窗 1~3 秒"——这是机制本身的问题，调参数无法解决。
**修复**：彻底重构为**「目标在场数」驱动**模型：屏幕始终维持固定数量敌机，缺一架补一架。开局先放 1 架，之后每隔 `gap` 补一架（依次进场）；击毁/漏过后最多 `gap` 毫秒即补位。生成速率 ≈ 在场数 ÷ 停留时间，天然稳定有度。

### 第 5 轮：目标在场数定档
按用户要求，目标在场数最终定为：**初级 3 架 / 中级 4 架 / 高级 5 架**，`aliveCap` 相应为 4 / 5 / 6（各 +1，随等级温和增长即封顶）。实测稳态正好 3/4/5 架。

### 难度封顶分析（初级示例）
`level` 数字无上限，但难度参数陆续封顶：

| 参数 | 封顶等级 | 所需分数 |
|---|---|---|
| 在场数 3→4 | LV.7 | 2400 |
| 下落速度 0.55→0.90 | LV.10 | 3600 |
| 补位间隔 700→280ms | LV.25 | 9600 |

LV.25 后难度到天花板，之后纯刷分展示，不会因玩到 LV.30/LV.50 突然失控。

## 五、交付与本地使用

### 任务 9｜最终打包
所有代码整合进单个 `拼音战机.html`（598 行，约 28KB，UTF-8），双击即可用浏览器打开，零依赖。自适应窗口缩放保证完整可见。

### 可选扩展（全部实现）
- 本局统计：总打字数量、正确率、平均打字速度（字/分）
- `localStorage` 保存历史最高分（`pinyinDefenseBest`）
- Web Audio 合成音效：击中 / 漏过 / 错误 / 失败 / 发射

### 桌面快捷方式
曾在桌面创建 `.url` 快捷方式，因对中文路径支持不佳改为直接复制 HTML 完整副本到桌面，双击即用浏览器打开（注意：桌面副本为静态快照，源码更新后需重新复制）。
